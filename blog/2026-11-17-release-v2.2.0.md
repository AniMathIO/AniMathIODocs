AniMathIO 2.2.0 brings community plugins and a reorganized Library. Extend the editor with third-party
tools and find media, elements, titles and effects in dedicated tabs. Download the installers from the
[2.2.0 release](https://github.com/AniMathIO/AniMathIO/releases/tag/v2.2.0).

## Community plugins

Community plugins are off by default. Turn on **Community plugins** in Preferences, install a bundle,
then enable it explicitly. Plugins run in a WebAssembly sandbox, but third-party code is not audited by
AniMathIO. Installation from an HTTPS URL requires a SHA-256 hash; local `.amplugin` files work too.
Enable, disable and remove plugins without restarting.

The Library's **Plugins → Browse** view lets you search the registry and install plugins, then enable or remove them under **Installed** or install a local bundle with **Install from file**.

The [community registry](https://github.com/AniMathIO/plugins) includes **Code Snippets**
(`io.github.animathio.code-snippets`), with syntax highlighting, reveal and token morph animations
inspired by Shiki Magic Move. See the [community plugins guide](/docs/community-plugins) for setup,
CLI commands and the trust model.

## A Library with a place for everything

- **Media:** imported video, images and audio, with media filters and grid/list views.
- **Elements:** text, LaTeX, shapes, graphs and grids, plus third-party clip sources.
- **Titles:** title and caption presets.
- **Effects:** video and audio effects, transitions, animation presets and Write on.
- **Plugins:** installed-plugin inventory, versions and load status.

Search belongs to the active tab, and each tab keeps its query and scroll position.

## Coloured LaTeX

Use `\color{red}{x}`, `\textcolor{blue}{y}` or a scoped `{\color{green} z}` inside a formula.
Explicit colours stay with their glyphs; unstyled glyphs inherit the clip colour. Write on works with
coloured formulas too. Plugin ABI 1.2 adds colour support while keeping existing 1.0 and 1.1 components
compatible.

## Flatpak build and fixes

This release adds offline Flatpak build files for `com.animathio.AniMathIO`. A Flathub listing is
pending; this is not an announcement of Flathub availability. The standard Windows, macOS and Linux
installers remain on the release page.

The Library cleanup also fixes duplicated creation tiles, misplaced media filters and scroll positions
leaking between tabs. The editor guide gains screenshots of the autocut review and markers panels.
See the [changelog](https://github.com/AniMathIO/AniMathIO/blob/main/CHANGELOG.md) for the full changes.

Follow the [Roadmap](https://github.com/AniMathIO/AniMathIO/issues/290) for upcoming work and
[Known issues](https://github.com/AniMathIO/AniMathIO/issues/291) for current limitations and workarounds.
