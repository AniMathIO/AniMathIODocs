We're excited to announce AniMathIO v1.6.3! This release marks a significant milestone with the introduction of our dashboard, expanded platform support, and important infrastructure improvements. As we focus on long-term sustainability, we're also shifting to yearly/bi-yearly major releases with security updates in between.

<!-- truncate -->

## What's New in v1.6.3

### Dashboard & Project Management

- **Dashboard Page**: Access important links, create new projects, open existing ones, and browse your project history all from one central hub
- **Project Search & Filtering**: Quickly find your projects with powerful search and filtering capabilities
- **Streamlined Workflow**: Start creating mathematical animations faster than ever

### Expanded Platform Support

- **Snap & Flatpak Builds**: AniMathIO is now available as Snap and Flatpak packages for easier installation on Linux distributions
- **AUR Package**: Arch Linux users can now install AniMathIO directly from the AUR at https://aur.archlinux.org/packages/animathio-bin
  - Special thanks to community member [zxp19821005](https://aur.archlinux.org/account/zxp19821005) for maintaining the AUR package!

### Improved User Experience

- **Open With Context Menu**: Right-click on AniMathIO project files and select "Open With" to launch them directly
- **Double-Click Support**: Open projects instantly by double-clicking them in your file manager
- **Gemini Model Integration**: Select the Gemini model when adding your API key in the settings UI for enhanced AI capabilities

### Technical Improvements

- **Node.js 24 & Dependencies**: Updated to the latest Node.js 24 with refreshed dependencies for improved performance and security
- **State & UI Fixes**: Resolved multiple state management and UI rendering issues for a more stable experience
- **Enhanced Testing**: Improved Vitest test coverage and reliability
- **CI/CD Enhancements**: Added CI script for automated release builds

## A Note on Our Release Cycle

As AniMathIO grows, we're transitioning to **yearly or bi-yearly major releases** to ensure quality and sustainability given our current resources. Between major releases, we'll provide **security updates** to keep your software safe and stable. This allows us to focus on building meaningful features rather than rushing frequent releases.
