AniMathIO 2.0.1 is a bug-fix and hardening release on top of [2.0](/blog/launching-v2.0.0), out the same day. Update by downloading the installer from the [release page](https://github.com/AniMathIO/AniMathIO/releases/tag/v2.0.1); projects need no migration.

<!-- truncate -->

## What changed

- **Security:** the ZIP reader behind `.amio` projects and `.amplugin` bundles is updated to zip 9 (critical advisory GHSA-m665-v7pm-7grj and related ones), and every remaining dependency advisory is fixed or documented.
- **Safer exports:** an export can no longer overwrite the project file that is open; exports to any other path work as before, from the editor, the CLI and MCP.
- **Safer saves:** JSON projects write each asset atomically and the manifest last, so a crash mid-save keeps the previous version intact.
- **A sturdier control protocol:** MCP and CLI clients get a clear error instead of waiting forever when the editor is busy or closed, while long jobs such as exports and transcription keep running to completion. Pipelined requests on one connection are no longer dropped.
- **Undo** keeps the last 500 steps, so very long sessions no longer grow memory without bound.
- **LaTeX:** `\tfrac` renders at text size.
- **Import and MCP fixes:** a crafted 1.x project with a huge `breathe` animation can no longer hang the importer; MCP `fadeOut` and `slideOut` animate the end of the clip; MCP `add_text` is a single undo step.
- **Update notice:** the editor checks GitHub at most once a day and shows a small notice when a newer 2.x release exists. Nothing is downloaded automatically and nothing else is sent; turn it off under Preferences or with `ANIMATHIO_NO_UPDATE_CHECK=1`.

The full list is in the [changelog](https://github.com/AniMathIO/AniMathIO/blob/main/CHANGELOG.md). Known problems and workarounds are collected in the pinned [Known issues](https://github.com/AniMathIO/AniMathIO/issues/291) issue, and what comes next is in the [Roadmap](https://github.com/AniMathIO/AniMathIO/issues/290).
