We're thrilled to announce the release of AniMathIO v1.5.0! This update brings significant improvements to our mathematical animation software, focusing on enhanced testing infrastructure, better user experience, and exciting new audio features.

<!-- truncate -->

## What's New in v1.5.0

### Enhanced User Experience

- **Space Hotkey**: Start or pause your animation playback with a simple press of the space bar, making it easier to preview your work as you create
- **Updated Help Menu**: Improved documentation access with direct links to our website, documentation, and Discord community
- **Fixed Rendering Issues**: Resolved critical bugs in mathematical element rendering for smoother animations

### Audio Improvements

- **Audio Mixer Panel**: We implemented a comprehensive audio mixer panel for advanced audio control
- **Audio Recorder Component**: Record your own audio directly within AniMathIO
- **Fixed Audio Bugs**: Resolved issues with audio volume changing and NaN time display in the resource panel

### Robust Testing Framework

- **Vitest Integration**: Installed and configured Vitest for comprehensive testing
- **Improved Test Coverage**: Significantly expanded our test suite, particularly for state-related functionality
- **Vitest UI Package**: Added a visual interface for better testing experience

### Under-the-Hood Improvements

- **Updated Dependencies**: Fixed installation and build errors with updated package versions
- **Backwards Compatibility**: Added backward compatible audio settings for project saving and loading
- **CI Test Runner Enhancements**: Multiple fixes for our automated testing pipeline
